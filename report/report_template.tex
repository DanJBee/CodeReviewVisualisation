    \begin{abstract}

        This report covers the design and development cycle of the \("\)Visualising Interactions Between Developers During Code Review\("\) UROP project.
        This includes the thought processes throughout the project,
        as well as the many challenges that were faced along the way and how these were dealt with.
        There are four primary milestones that were allocated and scheduled for this project:
        Crawler, Database, Frontend, and Backend.
        Firstly,
        the Crawler milestone was where pull request information from the TypeScript GitHub repository from Microsoft was fetched via the GitHub GraphQL API\@.
        Secondly,
        the Database milestone was the process
        of designing an appropriate relational database schema
        to hold this newly retrieved pull request information for easier analysis.
        Thirdly,
        the Frontend milestone was where mock data was inputted into a forced-directed graph powered by D3.js
        and React to replace this mock data with the pull request information from the relational database later on.
        Fourthly, and finally, the Backend milestone was the section of the project where everything came together.
        During this milestone,
        the frontend graph was linked to the backend API endpoint
        to allow data to be transferred to a callback from axios,
        a promise-based HTTP client for browsers and node.js.

    \end{abstract}
